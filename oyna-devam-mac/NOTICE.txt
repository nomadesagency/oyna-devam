What it does to your computer (read before installing):
  - Adds hooks and a permission rule to ~/.claude/settings.json (a backup is made first).
  - Copies its scripts to ~/.claude/oyna-devam/ and keeps a log there.
  - Optionally installs one sudoers rule (/etc/sudoers.d/claude-oyna-devam) that lets only
    "pmset schedule wake" / "pmset schedule cancel wake" run without a password.
  - Can suspend the Mac, wake it at a scheduled time, turn the display off and keep it awake (caffeinate).
It lets Claude Code run commands without asking for each approval while a task runs (depending on the
permission mode you pick). Only use it on tasks and folders you trust, keep backups of anything important,
and try it first on a small, non-critical task.

You can remove everything at any time: double-click uninstall.command (or run: bash uninstall.sh).
